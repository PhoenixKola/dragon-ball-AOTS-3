ATTACK OF THE SAIYANS III - CELL SAGA  (release candidate 1)
Private, offline fan-made game. No account, no network, no telemetry.

HOW TO PLAY
1. Extract this ZIP anywhere.
2. Double-click START_GAME.bat. A small local server starts (127.0.0.1 only) and your browser opens the game.
   (This player package bundles runtime\node.exe, so you do not need to install Node.js.)
3. Leave the black window open while playing; close it to stop the game.

CONTROLS
Move: WASD / arrows (Shift = run)   Interact: E / Enter / Space / Z   Menu: Tab or M   Back: X / Backspace (Esc is best-effort)
Fullscreen: F   Active Guard in battle: press 1 / 2 / 3 (the targeted fighter's slot) as the ring closes   Pause battle: P
Skip dialogue: K   Gamepad: A confirm, B back, Start menu, X/Y/RB guard slots 1/2/3, D-pad/stick move.

SAVES
Saved in this browser's local storage under the aots3.cell.v1.* namespace (3 slots + autosave, with backup copies).
Use Save/Load > Export to keep a JSON copy. Use the same browser and the same address (http://127.0.0.1:4173) to see your saves.
