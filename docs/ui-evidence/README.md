# UI harness captures

The PNGs and `report.json` produced in this directory by `node tests/e2e/ui-shots.mjs` are generated mock-session output. The Phaser canvas in that harness is black, so these images check React overlay layout only; they are not full-game visual evidence. The generated files are ignored by Git to keep the project download smaller. Use `docs/OVERHAUL_VISUAL_EVIDENCE_INDEX.md` for curated real-game captures.
