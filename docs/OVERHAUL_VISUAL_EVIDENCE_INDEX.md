# AOTS3 overhaul visual evidence index

This index preserves a concise before/after review set for the M0 baseline and art-bible work. The curated PNGs are committed under `docs/overhaul-evidence/`; the larger per-map, per-battle, and viewport captures remain in `tests/logs/screens/` and can be regenerated by the listed browser scripts.

## Capture rules

- `before/` combines the October RC baseline captures with pre-follow-up combat captures. The generated `docs/ui-evidence/` set was a UI-harness sweep: its Phaser canvas is black, so it verifies only the React overlay. Its PNGs are excluded from Git to keep the project download smaller; regenerate them with `node tests/e2e/ui-shots.mjs` if needed.
- `after/` uses fresh New Game screenshots for the opening, menu and P01 interaction states, plus real Phaser captures from natural story progress and isolated prop/VFX QA fixtures. Test-only fixtures are identified below and are not campaign-completion evidence.
- Human art approval remains separate from this technical visual review. Generated keyframes and props remain `approved=false` until owner review.

## Reproduction

- Fresh opening/menu/target/technique set: `node tests/e2e/overhaul-a-capture.mjs`.
- Android Island prop fixture: `node tests/e2e/android-island-pavilion-shot.mjs`.
- Natural campaign keyframe captures: `node tests/e2e/playthrough.mjs` (Normal, attentive policy, fresh New Game).
- Art audits: `python tools/audit_assets.py` and `npm run audit:runtime`.

## Natural progression checkpoint

`node tests/e2e/playthrough.mjs` completed the 30-beat story on Normal from New Game with no injected story flags, level boosts or stage skips. It won 34 battles, recorded 0 defeats, captured all 12 maps and the seven authored story keyframes, and reported zero browser errors and zero external requests. Exact run data is in `tests/logs/e2e-playthrough-attentive.json`. The targeted transformation run uses the same real New Game and story route and is indexed above. These are route/capture checks, not human play-feel acceptance.

The M0 technical review does not replace the final human art/gameplay review. Full campaign combat tuning, all-map/cutscene direction, release evidence and owner sign-off remain tracked under M1–M5.
